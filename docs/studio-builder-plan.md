# UI 스튜디오 → UI 빌더 설계

지금의 UI 스튜디오는 고정된 미리보기 한 장을 보여 준다. 이걸 **블록을 쌓아서 직접 화면을 만들고 내보내는 편집기**로 바꾼다.
빌드 도구 없이 지금처럼 정적 HTML/CSS/JS로 GitHub Pages에 올린다.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 편집 방식 | 블록 쌓기: 위에서 아래로 쌓고 ↑ ↓ 이동, 복제, 삭제 |
| 내보내기 | 내보내기 창에서 하나를 골라 실행: HTML 파일 하나 / 작업 파일(JSON) 저장·불러오기 / 코드 복사 |
| 구현 | ollama-pair: 코드는 Ollama, 설계·검수·판정은 Claude |
| 처음 화면 | 지금 미리보기 내용을 기본 템플릿 블록으로 그대로 시작 |

## 요청 5가지 → 기능

| # | 요청 | 구현 |
|---|---|---|
| 1 | UI 요소 더 추가 | 블록 종류를 지금 15종에서 약 24종으로: 통계 숫자, 요금표, 단계(1-2-3), 타임라인, 후기, 빈 화면, 검색바, 푸터, 구분선, 이미지 자리 등 |
| 2 | 추가·삭제·변경 + 내보내기 | "+ 요소 추가" 메뉴, 블록마다 ↑ ↓ 복제 삭제, 누르면 설정창. 내보내기 창 3가지 |
| 3 | 모바일·PC 미리보기 | 캔버스 위 전환 버튼: 모바일 390 / 태블릿 768 / PC 1280. 화면 폭이 아니라 **미리보기 틀 폭**에 반응하도록 CSS 컨테이너 쿼리 사용 |
| 4 | 특정 개체만 글자 크기 등 지정 | 설정창에서 그 블록만: 글자 크기, 굵기, 둥글기, 안쪽 여백, 정렬. "전체 설정 따르기"로 되돌리기 |
| 5 | 요소별 스킨 | 블록 종류마다 스킨 4~10개 + 모든 블록에 겹쳐 쓰는 **효과 5종**(그림자·테두리·배경·강조선·마우스 반응). 아래 "스킨과 효과" 참고 |

## 스킨과 효과

**스킨** = 블록 종류마다 고르는 완성된 모양 한 벌. **효과** = 어떤 블록에든 따로 켜고 끄는 층.
화면에는 둘이 겹쳐서 적용된다 (예: 카드 "강조선" 스킨 + "떠 있는 그림자" + "점선 테두리" + "마우스 올리면 떠오름").

### 블록별 스킨

| 블록 | 스킨 |
|---|---|
| 버튼 | 채움, 외곽선, 고스트, 부드러운(연한 바탕), 알약, 입체(아래 두께), 네오 브루탈(굵은 테두리+어긋난 그림자), 밑줄 글자, 큰 버튼, 작은 버튼 |
| 카드 | 평면, 테두리, 그림자, 떠 있는, 왼쪽 강조선, 위쪽 색띠, 반전(어두운), 연한 포인트색, 유리(반투명+흐림), 네오 브루탈, 점선 |
| 내비게이션 | 기본, 가운데 로고, 어두운, 떠 있는 바(둥근+그림자), 투명, 아래 선 |
| 히어로 | 왼쪽 정렬, 가운데 정렬, 좌우 분할(그림 자리), 반전 배경, 큰 숫자 강조, 포인트색 배경 |
| 입력칸 | 상자, 밑줄만, 채움(회색 바탕), 알약, 안쪽 그림자 |
| 탭 | 세그먼트, 밑줄, 알약, 상자 |
| 칩·뱃지 | 채움, 외곽선, 연한 바탕, 점 표시, 각진 태그, 그림자 |
| 표 | 선, 줄무늬, 격자, 카드형 행, 미니멀(머리글만 굵게) |
| 토스트·스낵바 | 어두운, 밝은+그림자, 포인트색, 왼쪽 강조선 |
| 알림 배너 | 연한 바탕, 왼쪽 선, 채움, 외곽선 |
| 모달 | 가운데 창, 하단 시트형, 경고(빨간 윗선), 전체 화면형 |

### 공통 효과 (모든 블록, 조합 가능)

| 효과 | 단계 |
|---|---|
| 그림자 | 없음 · 아주 약하게 · 약하게 · 보통 · 강하게 · 떠 있는(길고 넓게) · 안쪽 그림자 · 색 그림자(포인트색 번짐) · 하드 섀도(어긋난 실선) |
| 테두리 | 없음 · 실선 · 점선 · 이중선 · 굵게 |
| 배경 | 투명 · 표면 · 연한 포인트색 · 반전 · 유리 |
| 강조선 | 없음 · 왼쪽 · 위 · 아래 |
| 마우스 반응 | 없음 · 떠오름 · 살짝 커짐 · 밝아짐 · 눌림 |

- 그림자와 테두리 색은 고정값이 아니라 **테마 색에서 계산**한다(`color-mix`). 그래서 어두운 팔레트에서도 그림자가 어색하지 않다.
- 마우스 반응은 시스템 "동작 줄이기" 설정이면 끈다.
- 데이터에는 블록마다 `fx: {shadow, border, bg, accent, hover}`를 추가한다.

## 데이터 모델

```
project = {
  version: 2,
  theme:  { colors: {bg,title,sub,point}, vars: {radius,btnH,btnPx,fs,h1,gap,bw} },
  blocks: [ { id, type, skin, texts: {key: string},
              style: {fs?,fw?,radius?,pad?,align?},
              fx: {shadow?,border?,bg?,accent?,hover?} } ]
}
```
- 블록 하나 = 렌더 함수 하나. 블록의 개별 설정은 그 블록 루트에 CSS 변수(`--b-fs` 등)로만 넣고, 컴포넌트 CSS는 `var(--b-fs, var(--fs))`처럼 전역 값을 기본으로 쓴다.
- 저장: localStorage `ui-studio-v2`. 기존 v1의 색·슬라이더 값은 처음 한 번 옮겨 온다.

## 파일 구조 (전부 300줄 이하)

| 파일 | 역할 |
|---|---|
| `studio/index.html` | 3단 레이아웃: 왼쪽 테마 패널, 가운데 캔버스(기기 전환·요소 추가), 오른쪽 설정창(모바일에서는 아래 시트) |
| `studio/js/state.js` | 프로젝트 상태, 추가·삭제·복제·이동·수정, 저장·불러오기, 입력 검증 (Node에서도 테스트 가능) |
| `studio/js/components.js` | 블록 등록부 + 기존 요소 렌더 함수 |
| `studio/js/components-more.js` | 새 요소 렌더 함수 |
| `studio/js/inspector.js` | 설정창: 글자, 스킨, 개별 스타일 |
| `studio/js/export.js` | HTML 파일 만들기, JSON 저장·불러오기, 코드 복사 |
| `studio/js/app.js` | 전체 연결 (지금 `studio.js`의 팔레트·검색·슬라이더 로직을 옮김) |
| `studio/css/components.css` | 블록 기본 모양 |
| `studio/css/skins-a.css`, `skins-b.css` | 블록별 스킨 (종류가 많아 둘로 나눔) |
| `studio/css/effects.css` | 공통 효과 5종 |
| `studio/css/builder.css` | 편집기 화면 (선택 테두리, 블록 도구, 설정창, 기기 틀, 내보내기 창) |
| `tests/*.test.js` | `node --test`로 돌리는 상태·검증·내보내기 테스트 |

## Ollama 작업 순서

| # | 작업 | 확인 방법 |
|---|---|---|
| 1 | `state.js` + 테스트 | 추가·삭제·이동·복제·검증 테스트 통과 |
| 2 | `components.js` (기존 요소) | 지금 미리보기와 같은 화면이 블록으로 그려짐 |
| 3 | `components-more.js` (새 요소) | 새 블록 9종 렌더 |
| 4 | `components.css` | 컨테이너 쿼리 반응 (모바일 폭에서 카드가 한 줄로) |
| 5 | `skins-a.css` + `skins-b.css` | 블록마다 스킨을 바꾸면 모양이 바뀜 |
| 6 | `effects.css` | 효과 5종 조합, 어두운 팔레트에서 그림자 확인, 동작 줄이기 |
| 7 | `index.html` + `builder.css` | 3단 레이아웃, 모바일 시트 |
| 8 | `inspector.js` | 개별 글자 크기·스킨·효과 변경이 그 블록에만 적용 |
| 9 | `export.js` + 테스트 | 내보낸 HTML 단독 실행(쓴 스킨·효과만 포함), JSON 왕복, 글자 이스케이프 |
| 10 | `app.js` 연결 | 전체 시나리오 브라우저 검증 |

## 지켜야 할 것 (줄이면 안 되는 것)
- **불러온 JSON 검증:** 모르는 블록 종류·스킨은 버림, 숫자는 범위 안으로, 글자는 길이 제한.
- **내보낸 HTML의 글자 이스케이프:** 사용자가 입력한 글자가 코드로 실행되지 않게.
- **삭제 보호:** 블록을 지우면 "되돌리기" 스낵바를 띄움. 처음으로·불러오기는 덮어쓰기 전에 확인.
- **접근성:** 블록 도구 버튼에 이름, 키보드로 선택·이동, 포커스 표시, 대비 검사는 지금처럼 유지.

## 예상 시간과 위험
- Ollama가 파일 하나에 5~15분, 수정까지 포함하면 작업당 20~40분이 걸려서 전체로는 몇 시간이 걸린다.
- 이전 작업에서 Ollama의 JS 첫 버전에 치명적 버그가 많았다. 그래서 1번(상태)과 7번(내보내기)은 테스트를 먼저 정하고 시작한다.
